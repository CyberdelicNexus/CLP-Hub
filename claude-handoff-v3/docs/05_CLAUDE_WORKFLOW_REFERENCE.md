# Claude Taste + Scroll Craft workflow — V3

## Working rule

Protocol and participant agency set the boundaries. Taste decides how the page looks and reads inside those boundaries. Scroll Craft decides how the approved story unfolds over time. If motion weakens comprehension, accessibility or neutral choice, remove the motion.

## Required workflow

1. Read both installed skills completely and report their actual capabilities.
2. Audit the target repository and asset package.
3. Build the semantic static page before cinematic motion.
4. Verify all eight sections at desktop and mobile sizes.
5. Add the living-light interactions one section at a time.
6. Add touch and reduced-motion equivalents during each interaction, not at the end.
7. Run a Taste art-direction pass without changing the approved flow.
8. Run the real Scroll Craft/browser verification process available in the installed skill.
9. Fix blockers and high-severity issues and rerun failed checks.

## Non-negotiable checks

- V3 is the only storyboard.
- Exactly two randomized groups.
- No line trail in Section 2.
- Same light diameter in Sections 2 and 3.
- Quest 3 headset and controllers in the human reveal.
- Concept screenshots are not shipped as page backgrounds.
- All visible public copy is Spanish.
- No English-dependent video comprehension.
- Qualtrics CTA remains clear and usable without animation.

## Verification reporting

For every issue report:

- Severity: blocker / high / medium / low
- Viewport and section
- What failed
- Evidence
- Exact fix

Do not claim a check passed unless it was run and observed.
