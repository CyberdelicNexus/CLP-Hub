# Media and motion direction — V3

This file is current and replaces all earlier media sequencing.

## Media principle

The supplied low-resolution footage is the authentic numadelic material. Preserve its softness, darkness and ambiguous bodies. Do not sharpen it into generic VFX.

## Production derivatives

- Preserve original files.
- Create appropriately compressed web MP4/WebM derivatives when supported by the target stack.
- Create still posters from representative frames.
- Use `preload="metadata"` or `preload="none"` outside the first viewport.
- Pause media when it is no longer visible.
- Provide a quiet poster fallback when video fails or reduced motion is active.
- Keep essential text outside moving imagery.

## Effect boundaries

- Canvas UI Liquid may be considered only for the soft pointer reveal if it improves the feathered opacity blend without harming performance or accessibility.
- VGPU Flare may be considered only for the small orange fire light or a restrained heart glow. It is not a standalone section.
- Prefer supplied media, CSS masks, transforms and opacity before adding a renderer.
- No effect may create a second visual story or obscure study information.

## Motion rhythm

```text
Reveal humans -> coalesce -> rest below -> move above -> travel S0–S6
-> rest top-right -> divide into two -> dissolve at heart -> quiet orange fire
```

The experience should feel continuous, calm and legible. Do not add unrelated parallax, particle fields or ambient motion to every section.
